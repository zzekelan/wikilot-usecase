# 监督微调（SFT）

## 定义与范围

**监督微调**（Supervised Fine-Tuning，SFT）是在已有模型上，用输入及其目标输出进行监督训练。本页聚焦自回归语言模型：通过示范回答或行动轨迹，学习如何回答、遵循格式以及调用工具。SFT 是训练方式，不等于某一种数据来源或模型架构。

[[wiki/source/后训练与强化学习/instructgpt|InstructGPT]] 的 SFT 使用人类标注者示范微调 GPT-3，是这一概念的实例，而不是 SFT 的全部定义（§3.1、§3.5，第 6、8 页）。

## 优化什么

对示范数据 \(D=\{(x,y)\}\)，常见回答侧训练目标为：

\[
\mathcal L_{\rm SFT}(\theta)
=-\mathbb E_{(x,y)\sim D}\sum_{t=1}^{|y|}\log\pi_\theta(y_t\mid x,y_{<t}).
\]

训练时给定**示范前缀**，提高示范下一 token 的概率；这是逐 token 负对数似然，即 one-hot 目标的[[wiki/concept/概率与采样/交叉熵|交叉熵]]。公式对应 [[wiki/source/后训练与强化学习/gkd在策略蒸馏|GKD]] §3 的 SFT 定义（第 3 页）。实现中还要确定哪些 token 计入损失、按序列还是按 token 归一化；不能仅凭“SFT”三个字推断这些细节。

例如，目标回答是一次合法的工具调用，监督训练直接增加这串正确调用 token 的概率；它本身不要求实际执行工具并测量成功奖励。

## 能解决什么，不能保证什么

- 适合把已有能力塑造成稳定的输出格式、交互协议和任务行为。
- 示范覆盖不到的状态仍可能出错；生成时使用自己的前缀，训练时使用示范前缀，两种状态分布可能不同（GKD §3.1，第 3–4 页）。
- 更低示范损失不自动意味着更高用户满意度。InstructGPT 的验证损失与偏好评分出现不同趋势，说明应以目标行为共同选模型（第 8 页）。

## 与相邻方法的边界

- **指令微调**强调数据/任务形式；SFT 强调监督训练方式。并非所有 SFT 都是自然语言指令微调。
- **教师文本也能用于 SFT**：GKD 将教师生成序列上的最大似然称为 SeqKD；数据来自教师不等于在策略蒸馏（第 3 页）。
- **参数高效微调不是 SFT 的对立面**：更新哪些参数，与使用什么学习信号是两个维度。

在 [[wiki/source/大模型报告/deepseek-v4-1-flash|DeepSeek 报告]]中，SFT 是 RL 和 OPD 之前的阶段（第 25 页）；在 InstructGPT 中，独立 SFT 基线与 RL 初始化的 epoch/数据混合不同，具体设置见来源页附录 C 摘要。
