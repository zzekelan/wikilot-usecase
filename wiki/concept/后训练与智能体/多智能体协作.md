# 多智能体协作

## 机制与成本
多智能体协作通过并行探索、任务分工和交叉检查获得收益，也引入重复劳动、消息往返、上下文复制和写入冲突。依据：[[wiki/source/大模型报告/deepseek-v4-1-flash|报告]]第 35–36 页。

## 实例
[[wiki/entity/智能体系统/DeepSeek-Harness|DeepSeek-Harness]]的 Agent Team 用 lead 分派 fresh/fork teammate，以共享仓库、带 revision 的任务板和持久 mailbox 协调。advisory write scope 是建议写入范围，不等于强制锁；lead 仍需检查合并代码与测试。

## 评估边界
它是[[wiki/concept/后训练与智能体/测试时计算|测试时计算]]的并行分配方式，不能只按墙钟时间判定比单 agent 更节省算力。需要同时记录总 token、设备资源、agent 数和任务成功率。
