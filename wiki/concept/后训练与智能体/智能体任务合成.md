# 智能体任务合成

## 定义
智能体任务不是单独一道题，而是（问题，环境，验证系统）。任务合成构造三者的完整组合，使目标描述、可用工具和评分要求一致。依据：[[wiki/source/大模型报告/deepseek-v4-1-flash|报告]]第 25–26 页。

## 两类管线
通用 agent 根据自愿回传的工作流接口和失败案例构造 mocked 工具，保持输入输出格式、API schema 与业务约束，生成单轮或多轮环境。

代码 agent 从复杂/失败会话或 GitHub 项目选起点，先判断是否可容器化和自动验证，再建立依赖、工作目录、测试、描述并清除答案痕迹，打包镜像层。多个解题 agent 试做，独立质检后修复环境或调整难度（第 26 页）。

## 质量目标
正确性和难度共同构成构题训练奖励。不同于[[wiki/concept/正则化与校准/数据增强|数据增强]]对已有输入施加变换，这里扩展的是完整交互任务和反馈，[[wiki/entity/智能体系统/DSec|DSec]]提供大规模运行基础设施。
