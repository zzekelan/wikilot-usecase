# 困惑度（PPL）

## 定义与范围

**困惑度**（Perplexity，PPL）是平均负对数似然取指数后的指标。对 T 个计分 token：

\[
L=-\frac1T\sum_{t=1}^T\ln p(x_t\mid x_{<t}),\qquad \mathrm{PPL}=\exp(L).
\]

它衡量模型对已观测文本的概率预测表现；同一计分设置下越低越好。若用以二为底的平均代价 H₂，则 PPL=2ᴴ²。上述为由[[wiki/concept/交叉熵|交叉熵]]到语言建模指标的定义说明；[[wiki/source/deepseek-v4-1-flash|DeepSeek 报告]]第 24–25 页使用这一类概率评估，但没有在该段展开公式。

## 直观例子

若每个正确 token 都被赋予 0.5 的条件概率，L=ln 2，PPL=2。可以把它理解为平均预测不确定性的指数尺度，但不能据此断言模型每一步都真的在两个等概率候选间选择。

对整段序列，PPL 是正确 token 概率倒数的几何平均，不是每一步倒数概率的算术平均。

## 比较条件

PPL 按 token 归一化，因此比较时必须注意 tokenizer、计分文本、上下文长度、文档边界和哪些 token 被掩码。不同 tokenizer 把同一段文字切成不同数量的 token，PPL 不能据此直接横比。

即使分词相同，文本更容易或上下文更多也可能降低 PPL；低 PPL 不等于更好的工具使用或更高任务完成率。参见[[wiki/synthesis/评测指标的对象与可比条件|评测指标与可比性]]。

## 相关关系

PPL 与交叉熵单调对应，前提是平均单位和计分样本一致。与按字节计量指标的关系见[[wiki/synthesis/交叉熵-PPL与BPB的换算|概率指标换算]]。
