# 学习率与批量调度

## 定义与范围

学习率（Learning Rate，η）控制参数更新的步长尺度；批量大小（Batch Size）指一次梯度计算使用的数据量。学习率预热（Warmup）指训练初期逐渐提高学习率，衰减（Decay）指随后按计划降低学习率。本页关注训练调度，不讨论推理请求批处理。

最简单的梯度下降为 θₜ₊₁=θₜ−ηₜgₜ。学习率太小可能进展缓慢，太大可能震荡或发散；使用动量或自适应方法时，实际更新还取决于[[wiki/concept/动量-AdamW与权重衰减|优化器]]。出处：[[wiki/source/深度学习基础-2026暑期学校|课件]]第 61、65–71 页。

## 批量大小为什么相关

在适当采样假设下，大批量梯度的噪声通常更小，但计算代价和硬件效率也会变化。课件介绍批量乘 k、学习率也乘 k 的线性缩放经验，并指出初期需要预热、过大批量时规则可能失效；不能将它当作所有优化器和训练阶段的定律。出处：课件第 62–66 页。

比较批量时还要看单位：可以按样本、序列或 token 计数，三者不能直接互换。

## DeepSeek 的实际日程

[[wiki/source/deepseek-v4-1-flash|报告]]第 22 页给出的预训练设置为：

| 阶段 | 学习率 |
| --- | --- |
| 前 2000 步 | 线性预热至 2.6×10⁻⁴ |
| 预热后至累计 28T token | 保持 2.6×10⁻⁴ |
| 累计 28T–40T token | 余弦衰减至 2.6×10⁻⁵ |
| 累计 40T–45T token | 保持 2.6×10⁻⁵ |

报告固定批量为约 1.006 亿 token；部分参数另有学习率缩放。这是特定模型的训练配置，不是小模型应直接照搬的默认值。

调度影响损失能否稳定下降，也可能影响[[wiki/concept/泛化与数据质量|泛化]]，但降低训练损失本身不保证提升测试表现。阅读连接见[[wiki/synthesis/深度学习基础与DeepSeek报告的共同概念|共同概念对照]]。
