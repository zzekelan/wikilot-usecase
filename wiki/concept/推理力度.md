# 推理力度

## 定义与训练
Reasoning Effort 将资源偏好作为输入条件。报告用 b∈{1,…,100}，在 system prompt 加说明，同问题、同 b 组成子组并组内中心化奖励；不同力度不直接互相比奖励。依据：[[wiki/source/deepseek-v4-1-flash|报告]]第 29–30 页。

长度奖励 r_len(ℓ,b)=−min{C_max,k(b)ℓ/L_norm}，k(b)=k₀exp[−(b−b_min)/τ]。b 越高惩罚越弱，增加 τ 个力度单位使系数乘 e⁻¹。报告 API low/high/max 对应 50/75/100；这是行为偏好，不是硬 token 上限。

## 为什么采用指数惩罚
附录 C 在未触 cap 的区间优化 p_x(ℓ)−k(b)ℓ/L_norm。内部最优满足 p′_x(ℓ*)=k(b)/L_norm；若边际收益约 a_xexp(−ℓ/s_x)，则 ℓ*_x(b)≈s_xlog(a_xL_norm/k₀)+(s_x/τ)(b−b_min)。长度因而局部近似线性变化；cap 之后边际惩罚为零，推导不能直接沿用（第 49–51 页）。

## 选择依据
图 9 中 b=25→100，八项推理均值 67.1→76.3，DeepSWE 66.0→74.2，Terminal-Bench 2.1 为 82.4→90.6，输出约×2.5；附录存在平台与下跌（第 34–35、48–49 页）。它是[[wiki/concept/测试时计算|测试时计算]]的一种控制方式，而非统一的质量保证。
