# 通信—计算重叠

## 定义与条件
通信—计算重叠在不违反数据依赖的前提下并行执行传输和计算，减少关键等待。传输量减少与传输被掩盖是两种不同收益。依据：[[wiki/source/大模型报告/deepseek-v4-1-flash|报告]]第 16–18 页。

## 实例
对比学习中，视觉特征 all-gather 与文本前向重叠，文本特征 all-gather 与文本反向重叠。图像 I/O 可被计算掩盖的理想条件写为 Nρ/B_IO < NC/B_GPU；约去 N 后关键是原始每 token 字节数 ρ、计算量 C 与两种吞吐的比例。

该不等式只是容量条件，还需有调度空间和可重叠依赖。[[wiki/entity/模型与组件/Engram|Engram]]通过提前取表、梯度延后回传减少等待，仍必须保证数据在使用前到达。
