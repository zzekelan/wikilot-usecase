# 多模态训练解耦

## 动机
视觉编码涉及图像 I/O 与变长输入，语言主干更偏规则矩阵计算；把二者解耦可分别做负载均衡，再连接梯度路径。依据：[[wiki/source/大模型报告/deepseek-v4-1-flash|报告]]第 16–17 页。

## 三阶段流程
报告将视觉编码器放在 LLM 参数树之外，每步执行“视觉前向→LLM 前向/反向→视觉反向”。图像负载均衡限制在视觉阶段，语言阶段沿用文本训练并行策略。

百万 token 序列的图像按上下文并行 rank 均衡分片，每张图仅加载一次；rollout 增量传图并复用 CPU 预处理。它减少重复处理，并不取消视觉到语言的依赖关系。

## 边界
这是训练执行架构，不等于[[wiki/concept/架构与注意力/混合专家MoE|MoE]]中路由专家的负载均衡，也不同于服务时把预填充与解码拆开。
