# 评测协议

## 定义与记录项
评测协议界定被测系统及其运行和计分条件。智能体至少记录：

| 维度 | 内容 |
| --- | --- |
| 模型 | checkpoint、基础/后训练版本、推理力度 |
| 框架 | 名称、版本/commit、原生 prompt、工具 schema |
| 生成 | temperature、top-p、上下文、最大轮数 |
| 环境 | OS/容器、依赖、网络和资源权限 |
| 数据 | 基准版本、子集、题数 |
| 统计 | 每题采样数、评分、失败处理、区间 |

依据：[[wiki/source/大模型报告/deepseek-v4-1-flash|报告]]第 32–35、47–48 页。

## 比较对象
等模型等预算比较[[wiki/concept/后训练与智能体/智能体框架|智能体框架]]，研究交互设计；统一框架比较模型，研究模型差异；两者都变则是联合系统比较。网络、缓存和评分隔离会改变实际任务，不能当作无关部署细节。

表 4 固定 effort=100、1M context、temperature=1、top-p=.95、max_steps=500。DeepSWE 每题 N=8、Terminal 每题 N=3 用于估计单次表现，不能读成 Pass@8/Pass@3。
