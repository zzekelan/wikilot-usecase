# KV 缓存

## 定义
KV cache 保存注意力中历史位置的 Key/Value，新 token 的 query 可直接读取这些状态，不必每步重算整个前缀。依据：[[wiki/source/deepseek-v4-1-flash|报告]]第 4–6、9 页。

## 范围与生命周期是不同维度
全局 KV 可覆盖整个上下文，报告包含 main KV 与 indexer K；局部 SWA KV 覆盖最近窗口。持久 KV 则指跨请求保留的副本，可位于主机内存或 SSD。同一全局状态既可有运行时副本，也可持久保存，“全局”和“持久”并不互斥（第 4、19–20 页）。

## 容量口径
常规缓存粗计为 N×L×2×n_KV×d_head×每元素字节数；压缩 latent、跨层共享等会改变计数，须按布局核算。报告全局 KV 为 890 B/token，百万 token 约 890 MB（十进制），不含权重、SWA 和激活（第 1、19、37 页）。

缓存更小不等于推理必然同比例更快，还要看读取、计算、命中率和并发。
