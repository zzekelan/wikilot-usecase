# Bootstrap

## 方法
Bootstrap 从观测数据重采样，重复计算统计量，以其波动构造区间等不确定性估计。Arena 比较 pivot bootstrap 与 sandwich 方法。依据：[[wiki/source/模型评测/chatbot-arena|Arena]]第 5、16 页。

## 为什么重采样单位重要
重采样应反映原数据的依赖结构。若同一用户多次投票相关，简单把每票视为独立样本可能低估不确定性；应针对相关结构选合适单位或方法。

## 不是增加真实样本
更多重采样次数改善计算近似，却不增加独立用户信息。能否获得正确[[wiki/concept/偏好与统计/置信区间|置信区间]]覆盖，还依赖估计量、样本规模与重采样设计；不能把任何 bootstrap 区间都当作自动稳健。
