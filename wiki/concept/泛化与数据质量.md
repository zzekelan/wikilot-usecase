# 泛化与数据质量

## 定义与范围

泛化（Generalization）指模型在训练样本之外的数据上表现良好的能力。过拟合（Overfitting）指模型过度适应训练样本的细节或噪声，使训练表现无法代表目标分布上的表现。本页讨论数据、模型容量、训练过程与评估的关系，不把泛化归结为参数量一个因素。

课件用带噪正弦曲线的多项式拟合展示：模型可以穿过训练点，却在点间剧烈震荡；增加数据或适当约束可以改善预测。后续的随机标签实验和双下降进一步说明，不能把“大模型一定更容易过拟合”当作普遍规律。出处：[[wiki/source/深度学习基础-2026暑期学校|课件]]第 10–21、79–81 页。

## 数据质量为什么重要

有效数据不仅取决于样本数，还取决于正确性、覆盖范围、重复程度和与目标任务的相关性。重复低质量内容不等于增加同等数量的新信息。

[[wiki/source/deepseek-v4-1-flash|DeepSeek 报告]]第 20–21 页介绍过滤、去重及数据配比；第 25 页强调后训练任务的多样性、正确性、难度和可验证性。这是课件“数据影响学习结果”的具体应用。任务合成创造新的问题、环境与验证信号，与图像翻转等数据增强并非同一种操作。

## 从原始语料到多模态训练集

报告第 20–21 页把质量控制贯穿处理管线：

1. 文本侧用领域专家质量维度和 scaling ladder 选择语料配比，过滤信息增益低的模型输出、低质机器翻译，增加近期代码、提交与依赖覆盖。
2. 图文对从网页图像和 alt text 提取，做相关性过滤及图像语义去重。
3. 交错图文先做廉价文档筛选，再下载/处理图像、进行图像感知过滤和 SmolVLM 评分；部分文档回收为图文对，降低处理浪费。
4. 补充 OCR、视觉定位、图像代码与 computer-use 轨迹等领域数据。
5. 合并时以多模态版本替代重叠纯文本，最终 token 比为文本:多模态=7:1；跨预训练与长上下文扩展协调样本分配，并以 packing 将 padding 控制在 10⁻⁴ 以内。

这里同时优化了信息覆盖和处理成本；更多 token 是否有益，取决于新增的是有效信息还是重复内容。后训练进一步把质量单位扩展为[[wiki/concept/智能体任务合成与验证|问题、环境与验证系统]]。

## 怎样评估

训练集用于拟合参数，验证集用于选择超参数，测试集用于最终评估。反复依照测试结果调参会引入选择偏差；来源：课件第 19–20 页。若实际部署数据与评估数据分布不同，原有结果也未必适用。

报告第 24–25 页使用内部文档、代码、学术资料的留出集，第 32 页说明任务评测配置；内部语料规模和隔离审计未披露。[[wiki/concept/评测污染与奖励投机|评测隔离]]与任务执行中的防投机需要分别处理。

[[wiki/source/chatbot-arena|Arena 论文]]第 3、6、8–9 页提供另一种分布问题：提示题材多样，但用户主要为爱好者和研究人员、语言以英语为主。主题覆盖广不等于真实用户群体采样均衡；模型的偏好排名会随人群和任务配比变化。
