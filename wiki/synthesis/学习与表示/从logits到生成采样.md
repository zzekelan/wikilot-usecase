# 从 logits 到生成采样

## 三个概念各做一件事

| 概念 | 作用 | 不负责什么 |
| --- | --- | --- |
| [[wiki/concept/概率与采样/Softmax|Softmax]] | 将 logits 归一化为概率 | 不决定采用贪心还是随机采样 |
| [[wiki/concept/概率与采样/温度采样|温度采样]] | 调整概率集中度，再按概率抽取 | 不直接规定思考预算 |
| [[wiki/concept/概率与采样/核采样top-p|核采样（top-p）]] | 根据累计概率截断候选集合 | 不保证保留 token 是正确答案 |

一种常见生成流程是 **logits → 温度缩放 → Softmax → top-p 截断及归一化 → 抽样**；具体框架可能还加入屏蔽、重复惩罚等操作，应核对其顺序。Softmax 的数学基础见[[wiki/source/深度学习基础/深度学习基础-2026暑期学校|课件]]第 27–29、38 页，top-p 的解释和手算见对应概念页。

## 为什么两个参数要一起看

温度缩放保持固定 logits 的排序，但改变累计概率，因此会影响 top-p 最终保留几个候选。也就是说，“温度相同”不意味着“抽样分布相同”；“top-p 相同”也不意味着“候选数量相同”。这是按两个算法定义得到的关系。

[[wiki/source/大模型报告/deepseek-v4-1-flash|DeepSeek 报告]]第 32 页的推理评估使用 temperature=1、top-p=1，代码智能体使用 temperature=1、top-p=0.95。报告的差异来自具体协议，不能把某个配置当成所有任务的推荐值。

## 与训练、校准和预算分开

- 训练中，Softmax 概率配合[[wiki/concept/概率与采样/交叉熵|交叉熵]]优化模型参数；生成时调整采样参数通常不更新权重。
- [[wiki/concept/正则化与校准/置信度校准|分类校准]]中的温度是为匹配经验正确率而拟合，和为了多样性手动调温度的目标不同。
- [[wiki/concept/后训练与智能体/推理力度|推理力度]]控制模型学到的推理行为与计算使用，不能用采样温度直接替代。
