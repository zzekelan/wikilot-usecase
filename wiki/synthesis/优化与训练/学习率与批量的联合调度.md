# 学习率与批量的联合调度

[[wiki/concept/优化与调度/学习率|学习率]]控制步长尺度，[[wiki/concept/优化与调度/批量大小|批量大小]]影响噪声和吞吐；[[wiki/concept/优化与调度/学习率预热|学习率预热]]与[[wiki/concept/优化与调度/学习率衰减|学习率衰减]]构成随进度变化的日程。线性缩放规则只是经验，不是任意优化器的定律（[[wiki/source/深度学习基础/深度学习基础-2026暑期学校|课件]]第 61–66 页）。

## DeepSeek 的具体训练日程
| 阶段 | 学习率 |
| --- | --- |
| 前 2000 步 | 线性预热至 2.6×10⁻⁴ |
| 预热后至累计 28T token | 保持 2.6×10⁻⁴ |
| 28T–40T token | 余弦衰减至 2.6×10⁻⁵ |
| 40T–45T token | 保持 2.6×10⁻⁵ |

固定批量约 1.006 亿 token，Engram 学习率另×5。序列从 64K 起训，在 34T 时扩至 1M；视觉编码器在 28T 开始衰减阶段解冻并用较小学习率。长度、解冻与优化共同组成流程，不能只复现一条曲线。依据：[[wiki/source/大模型报告/deepseek-v4-1-flash|报告]]第 15、22 页。
