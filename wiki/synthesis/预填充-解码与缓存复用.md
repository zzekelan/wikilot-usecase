# 预填充、解码与缓存复用

[[wiki/concept/预填充|预填充]]处理已知输入，[[wiki/concept/自回归解码|自回归解码]]生成未知后缀，[[wiki/concept/KV缓存|KV缓存]]为两阶段保存可复用状态，[[wiki/concept/前缀缓存复用|前缀缓存复用]]再把复用延伸到多个请求。

| 优化方向 | 相关方法 |
| --- | --- |
| 减少长输入计算 | [[wiki/concept/CED因果编码器解码器|CED]] |
| 减少重复存储和索引 | [[wiki/concept/CSA2压缩稀疏注意力|CSA2]] |
| 缩小持久状态 | [[wiki/concept/SWA有界重放|SWA有界重放]] |
| 降低每值位宽 | [[wiki/concept/FP4缓存量化|FP4缓存量化]] |

全局 KV 的 890 B/token 不代表全部部署显存。比较效率需同时看输入/输出长度、首 token 延迟、输出速度、缓存命中和吞吐，而非把存储节省比例直接当作加速比例。依据：[[wiki/source/deepseek-v4-1-flash|报告]]第 4–6、9、19–20、37 页。
