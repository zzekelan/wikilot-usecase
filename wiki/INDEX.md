## 概念

### 学习目标、模型选择与泛化

目录：`wiki/concept/学习理论/`。

- [[wiki/concept/学习理论/经验风险|经验风险]] — 训练样本平均损失及其与总体风险的区别。
- [[wiki/concept/学习理论/最小二乘|最小二乘]] — 最小化平方残差，说明正规方程、唯一性与伪逆解。
- [[wiki/concept/学习理论/岭回归|岭回归]] — 线性平方损失加 L2 惩罚的闭式解与正则强度选择。
- [[wiki/concept/学习理论/模型选择|模型选择]] — 区分参数拟合、超参数选择与最终独立评估。
- [[wiki/concept/学习理论/交叉验证|交叉验证]] — 通过轮换训练与验证子集估计配置表现。
- [[wiki/concept/学习理论/泛化|泛化]] — 模型在训练样本之外、目标分布上的预测能力。
- [[wiki/concept/学习理论/过拟合|过拟合]] — 过度适应有限样本细节，使训练表现不能代表新数据。
- [[wiki/concept/学习理论/数据质量|数据质量]] — 正确性、覆盖、去重和目标相关性共同决定有效训练信息。
- [[wiki/concept/学习理论/偏差方差分解|偏差—方差分解]] — 平方预测误差的偏差平方、方差与不可约噪声恒等式。
- [[wiki/concept/学习理论/双下降|双下降]] — 插值阈值附近误差升高、继续增加容量后再次下降的现象。

### 概率预测与生成采样

目录：`wiki/concept/概率与采样/`。

- [[wiki/concept/概率与采样/交叉熵|交叉熵]] — 目标分布的负对数代价、最大似然联系及分类输出梯度。
- [[wiki/concept/概率与采样/困惑度PPL|困惑度（PPL）]] — 平均 token 负对数似然的指数，强调分词和计分条件。
- [[wiki/concept/概率与采样/每字节比特数BPB|每字节比特数（BPB）]] — 按文本字节归一化的概率代价，独立解释 DeepSeek 内部语料结果。
- [[wiki/concept/概率与采样/Softmax|Softmax]] — logits 到概率的归一化函数、平移不变性与稳定计算。
- [[wiki/concept/概率与采样/温度采样|温度采样]] — 缩放 logits 调节抽样集中度，区分校准、贪心与思考预算。
- [[wiki/concept/概率与采样/核采样top-p|核采样（top-p）]] — 按累计概率动态截断候选集合，再归一化采样。

### 网络表示、激活与归一化

目录：`wiki/concept/网络组件/`。

- [[wiki/concept/网络组件/多层感知机MLP|多层感知机（MLP）]] — 以可学习仿射变换和非线性激活逐层构建表示。
- [[wiki/concept/网络组件/通用近似定理|通用近似定理]] — 在给定函数与激活条件下，足够宽网络具有逼近能力的存在性结论。
- [[wiki/concept/网络组件/激活函数|激活函数]] — 作用于中间特征的非线性映射，区别于尺度归一化。
- [[wiki/concept/网络组件/ReLU|ReLU]] — 正半轴线性、负半轴为零的激活函数。
- [[wiki/concept/网络组件/LeakyReLU|LeakyReLU]] — 在负半轴保留小斜率的 ReLU 变体。
- [[wiki/concept/网络组件/Sigmoid|Sigmoid]] — 将实数映射到零至一之间的饱和函数。
- [[wiki/concept/网络组件/Tanh|Tanh]] — 零中心、值域为负一至一的双侧饱和激活。
- [[wiki/concept/网络组件/GELU|GELU]] — 以高斯累积分布对输入加权的平滑激活。
- [[wiki/concept/网络组件/SiLU|SiLU]] — 以 Sigmoid 对输入自门控的平滑激活。
- [[wiki/concept/网络组件/SwiGLU|SwiGLU]] — 以 SiLU 门控分支和特征分支相乘构成前馈结构。
- [[wiki/concept/网络组件/BatchNorm|BatchNorm]] — 按批量等统计轴标准化激活，并使用可学习仿射变换。
- [[wiki/concept/网络组件/LayerNorm|LayerNorm]] — 在单样本或单位置的指定特征维上标准化。
- [[wiki/concept/网络组件/RMSNorm|RMSNorm]] — 按均方根归一化特征，通常省略减均值步骤。

### 梯度计算与参数初始化

目录：`wiki/concept/梯度与初始化/`。

- [[wiki/concept/梯度与初始化/反向传播|反向传播]] — 沿计算图逆序应用链式法则，复用中间结果计算梯度。
- [[wiki/concept/梯度与初始化/梯度消失|梯度消失]] — 链式求导中的导数乘积持续收缩，削弱早层更新信号。
- [[wiki/concept/梯度与初始化/梯度爆炸|梯度爆炸]] — 链式求导中的导数乘积放大，造成过大更新与数值不稳定。
- [[wiki/concept/梯度与初始化/参数初始化|参数初始化]] — 通过非对称起点和合适数值尺度启动参数学习。
- [[wiki/concept/梯度与初始化/Xavier初始化|Xavier 初始化]] — 以输入与输出宽度折中前向和反向信号尺度。
- [[wiki/concept/梯度与初始化/He初始化|He 初始化]] — 按 ReLU 二阶矩变化选取权重尺度的初始化规则。

### 正则化与概率校准

目录：`wiki/concept/正则化与校准/`。

- [[wiki/concept/正则化与校准/正则化|正则化]] — 通过目标、更新、训练过程或数据改变学习偏好。
- [[wiki/concept/正则化与校准/L1正则化|L1 正则化]] — 以参数绝对值和惩罚幅度，常产生稀疏解。
- [[wiki/concept/正则化与校准/L2正则化|L2 正则化]] — 以参数平方范数惩罚幅度，在梯度中加入线性收缩项。
- [[wiki/concept/正则化与校准/权重衰减|权重衰减]] — 在参数更新中直接按比例收缩权重。
- [[wiki/concept/正则化与校准/早停|早停]] — 以验证表现决定停止时机并恢复最佳参数。
- [[wiki/concept/正则化与校准/Dropout|Dropout]] — 训练中随机屏蔽激活，改变网络对固定特征组合的依赖。
- [[wiki/concept/正则化与校准/数据增强|数据增强]] — 用与任务语义一致的输入或输入—目标变换扩展训练覆盖。
- [[wiki/concept/正则化与校准/标签平滑|标签平滑]] — 将硬目标与平滑分布混合，改变监督训练目标。
- [[wiki/concept/正则化与校准/置信度校准|置信度校准]] — 使预测概率与经验正确率相符，而不是仅提高准确率。

### 优化器与训练调度

目录：`wiki/concept/优化与调度/`。

- [[wiki/concept/优化与调度/损失曲面|损失曲面]] — 参数到损失的几何结构，区分梯度、曲率和全局性质。
- [[wiki/concept/优化与调度/随机梯度下降SGD|随机梯度下降（SGD）]] — 用随机样本或小批量梯度近似总体训练梯度并更新参数。
- [[wiki/concept/优化与调度/动量|动量]] — 积累历史梯度以保留稳定方向、缓和来回震荡。
- [[wiki/concept/优化与调度/Nesterov动量|Nesterov 动量]] — 在历史方向的前瞻位置修正梯度更新。
- [[wiki/concept/优化与调度/AdaGrad|AdaGrad]] — 累计历史梯度平方，为各参数调整更新尺度。
- [[wiki/concept/优化与调度/RMSProp|RMSProp]] — 用梯度平方的指数平均调节逐坐标步长。
- [[wiki/concept/优化与调度/Adam|Adam]] — 结合梯度一阶矩、二阶矩和零初始化偏差修正的优化器。
- [[wiki/concept/优化与调度/AdamW|AdamW]] — 将权重衰减从 Adam 的自适应梯度更新中解耦。
- [[wiki/concept/优化与调度/Muon|Muon]] — 对动量矩阵近似正交化并缩放的优化方法。
- [[wiki/concept/优化与调度/Sinkhorn矩阵更新|Sinkhorn 矩阵更新]] — 对有效更新行列交替归一化，近似均衡 RMS。
- [[wiki/concept/优化与调度/学习率|学习率]] — 控制优化器参数更新尺度的超参数。
- [[wiki/concept/优化与调度/批量大小|批量大小]] — 一次梯度计算使用的数据量及其噪声和硬件成本。
- [[wiki/concept/优化与调度/学习率预热|学习率预热]] — 训练初期逐步增大学习率以缓和未稳定状态下的更新。
- [[wiki/concept/优化与调度/学习率衰减|学习率衰减]] — 按训练进度降低步长以平衡优化速度和后期波动。

### 模型架构与注意力

目录：`wiki/concept/架构与注意力/`。

- [[wiki/concept/架构与注意力/混合专家MoE|混合专家（MoE）]] — 按 token 选择少量专家子网络进行条件计算。
- [[wiki/concept/架构与注意力/多模态专家负载均衡|多模态专家负载均衡]] — 按模态独立调节专家选择，避免总量均衡掩盖模态内偏斜。
- [[wiki/concept/架构与注意力/CED因果编码器解码器|CED 因果编码器–解码器]] — 从 encoder 状态生成 decoder 全局 KV，减少 prefill。
- [[wiki/concept/架构与注意力/CSA2压缩稀疏注意力|CSA2 压缩稀疏注意力]] — Full、Reindex、Reuse 解耦 KV 共享与索引复用。
- [[wiki/concept/架构与注意力/分层稀疏索引|分层稀疏索引]] — 从全局候选块到共享候选池，再做逐层 Top-K。
- [[wiki/concept/架构与注意力/滑动窗口注意力SWA|滑动窗口注意力（SWA）]] — 每层只关注当前位置附近固定宽度的历史窗口。
- [[wiki/concept/架构与注意力/流形约束超连接mHC|流形约束超连接（mHC）]] — 以受约束的混合映射在块间传递多条残差流。
- [[wiki/concept/架构与注意力/Single-Pass-mHC|Single-Pass mHC]] — mHC 的依赖重排变体，复用前块系数以实现单遍残差流融合。

- [[wiki/concept/偏好与统计/成对比较|成对比较]] — 通过相同问题下两个候选的相对选择收集评价。

- [[wiki/concept/偏好与统计/Bootstrap|Bootstrap]] — 通过重采样和重复拟合近似估计量抽样波动。
- [[wiki/concept/偏好与统计/Sandwich稳健方差|Sandwich 稳健方差]] — 结合损失曲率和梯度波动估计渐近协方差。
- [[wiki/concept/偏好与统计/同时统计推断|同时统计推断]] — 为多个参数或模型的联合结论控制覆盖或错误率。
- [[wiki/concept/偏好与统计/近似排名|近似排名]] — 由同时分数区间推导保守名次范围，而非强行给出唯一顺序。
- [[wiki/concept/偏好与统计/主动采样|主动采样]] — 利用已有观测将下一次采样分配给更能降低不确定性的对象。
- [[wiki/concept/偏好与统计/逆概率加权IPW|逆概率加权（IPW）]] — 用实际抽样概率的倒数或目标与实际分布之比校正估计。
- [[wiki/concept/偏好与统计/异常投票检测|异常投票检测]] — 秩 p 值、有限次数检查与混淆矩阵。
- [[wiki/concept/偏好与统计/主题建模|主题建模]] — 从文本集合提取主题结构，用于理解内容分布。
- [[wiki/concept/偏好与统计/LLM评审|LLM 评审]] — 用语言模型依照评价标准判断回答质量。

### 评测指标与有效性

目录：`wiki/concept/评测方法/`。

- [[wiki/concept/评测方法/完全匹配率EM|完全匹配率（EM）]] — 按指定归一化规则与标准答案完全匹配的比例。
- [[wiki/concept/评测方法/F1分数|F1 分数]] — 精确率与召回率的调和平均，依赖匹配单位与聚合方式。
- [[wiki/concept/评测方法/Pass-at-k|Pass@k]] — k 次候选中至少一次达到成功条件的概率。
- [[wiki/concept/评测方法/Mean-at-k|Mean@k]] — 同一任务 k 次尝试得分的平均，而非至少一次成功率。
- [[wiki/concept/评测方法/任务解决率Resolved|任务解决率（Resolved）]] — 按基准完成条件判定单次任务是否解决，再汇总成功比例。
- [[wiki/concept/评测方法/Almost-at-1|Almost@1]] — 按一次尝试达到指定近完成阈值统计成功比例。
- [[wiki/concept/评测方法/评测协议|评测协议]] — 规定模型、数据、环境、生成和统计口径以支持复现比较。
- [[wiki/concept/评测方法/评测污染|评测污染]] — 测试内容、答案或受保护资源进入训练或解题上下文。
- [[wiki/concept/评测方法/选择过拟合|选择过拟合]] — 反复依据有限评估结果挑选配置，导致被选成绩偏乐观。
- [[wiki/concept/评测方法/奖励投机|奖励投机]] — 通过评分代理或环境漏洞得分，而非完成预定目标。
